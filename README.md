# Recording Academy — Website Performance Analysis

Excel analysis examining whether splitting grammy.com and 
recordingacademy.com into two separate domains improved 
user engagement.

## View the Analysis
Download `Recording_Academy_Website_Analysis.xlsx` to view 
the full analysis with charts, PivotTables, and findings.

## Overview
In February 2022, The Recording Academy — the non-profit 
behind the Grammy Awards — split their single website into 
two domains: grammy.com for the awards show and fan audience, 
and recordingacademy.com for their industry and professional 
community. This analysis examines whether that decision 
improved user engagement using real web traffic data 
spanning 2017–2023.

## Key Findings
- recordingacademy.com outperforms on every engagement KPI after the split
- Grammy Awards night generates 43x more traffic than a normal day (1,389,590 vs 32,388)
- 73.7% of grammy.com visitors are on mobile devices
- A/B test confirms the split increased CTA click-through rate from 3.13% to 3.85%
